## 项目简介

HiLLM NAV 是一个开源的 AI 资源导航与内容社区项目，围绕 AI 工具、Skills、MCP Server、Prompts 与社区内容，提供发现、投稿、整理和运营所需的完整能力。

仓库仅包含应用源码、数据库结构迁移与安全的示例配置；不包含生产数据库、用户上传文件、访问密钥或其他真实业务数据。

## 功能介绍

### AI 资源导航

围绕 AI 工具、网站与开发者资源建立可持续维护的内容目录。访客可以按分类浏览、关键词搜索、查看热门排行和收藏感兴趣的内容；管理员则可维护分类、站点信息、展示状态与推荐内容。

### Skills、MCP 与 Prompts

为可复用的 AI 能力提供独立内容空间：

- **Skills**：展示和投稿可复用的 AI 工作流、方法与技能说明。
- **MCP Server**：收录模型上下文协议服务，帮助用户发现可连接的工具能力。
- **Prompts**：沉淀可复用的提示词内容，支持详情展示、投稿与后台维护。

不同类型的内容均拥有独立详情页、分类与投稿流程，便于用户从发现资源到实际使用形成连续体验。

### 内容创作与社区

项目内置面向创作者和使用者的内容社区。用户可发布问答、新闻与作品，浏览公开内容，并在个人主页中展示自己的公开资料和创作内容。通知与账号中心集中处理日常的互动、投稿和个人设置。

### 投稿与内容审核

前台提供网站、Skills、MCP Server 与 Prompts 等内容的投稿入口；后台提供对应的审核、编辑、发布和下线能力。内容运营者可以统一处理分类、封面、描述、外部链接与展示状态，保持目录信息清晰、可维护。

### 管理后台

后台覆盖站点日常运营所需的主要模块，包括：

- 内容、分类与投稿管理
- 用户、访问权限与账号相关设置
- 媒体资源与文件管理
- 站点配置、邮件与基础设施设置
- 安全中心与内容安全检查

### 账号、媒体与安全

支持邮箱验证、OAuth 登录、公开个人主页和基于角色的访问控制。上传内容通过统一媒体能力管理，可使用本地文件系统或对象存储；项目同时提供可选的隔离安全扫描服务，帮助运营侧识别需要进一步核对的内容。

## 技术栈

- Next.js 16、React 19、TypeScript
- HeroUI v3、Tailwind CSS v4
- PostgreSQL 17、Better Auth
- Tiptap、React Markdown、Lowlight
- Vitest、ESLint

## 本地运行

环境要求：Node.js 20.19 或更高版本、pnpm，以及 Docker（用于本地 PostgreSQL）。

```bash
git clone https://github.com/oxomkbk/Hi-LLM.git
cd Hi-LLM
pnpm install
cp .env.example .env
docker compose up -d control-postgres business-postgres
pnpm db:migrate
pnpm dev
```

启动后访问 [http://localhost:3000](http://localhost:3000)。`.env.example` 仅提供本地开发示例；请为正式环境生成独立密钥，且不要提交 `.env`、数据库导出、上传目录或云服务凭据。

## 常用命令

```bash
pnpm dev          # 启动开发服务
pnpm build        # 构建生产版本
pnpm start        # 启动生产服务
pnpm lint         # 运行代码检查
pnpm typecheck    # 运行 TypeScript 检查
pnpm test         # 运行单元测试
pnpm db:migrate   # 执行数据库迁移
```
